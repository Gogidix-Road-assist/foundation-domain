### Deployment Steps

1. **Environment Configuration**
   ```bash
   export ALLOWED_ORIGINS="http://localhost:3000,http://localhost:8080,https://rapidassist.gogidix.com"
   export MONGODB_URI="mongodb://localhost:27017/rapidassist"
   ```

2. **Build All Services**
   ```bash
   cd Foundation-Domain/shared-infrastructure/Backend/Java
   mvn clean package -DskipTests
   ```

3. **Build Docker Images**
   ```bash
   # Build individual service images
   cd <service-directory>
   docker build -t gogidix/<service-name>:1.0.0 .
   ```

4. **Run Services**
   ```bash
   docker-compose up -d  # Or orchestrate via Kubernetes
   ```

5. **Verify Deployment**
   - Health checks: `curl http://localhost:<port>/actuator/health`
   - API docs: `http://localhost:<port>/swagger-ui.html`
